# Skill: 小红书内容探索者 (Content Explorer)

## 🚨 强制执行铁律

### 1. 点赞优先与 100% 执行
- **强制动作顺序**：识别到符合目标且达标的**图文**笔记后，**第一动作必须是点击点赞按钮，第二动作才是记录标题**。
- **严禁漏赞**：只要打算记录在 summary 中的图文笔记标题，对应的笔记必须已经点赞。
- **不设上限**：在巡逻期间，符合标准的内容 100% 强制点赞。

### 2. 视频笔记特殊处理
- **识别特征**：笔记卡片**右上角**有白色/半透明**播放图标（▶️ 或三角形）**即判定为视频笔记。
- **处理规则**：
  - 允许点击进入详情页浏览。
  - **严禁**点赞、收藏。
  - **严禁**在 summary 中记录 `[SHOT]` 或 `[CONTENT]`。
  - 在 thought 中必须记录："检测到视频笔记，仅浏览未进行互动和收割"。

### 3. 高质量筛选 (≥100 赞硬性红线)
- **硬性门槛**：点赞数必须 **≥ 100**。严禁点赞、收藏或记录任何点赞数低于 100 的笔记。
- **负向确认**：执行任何点赞或进入笔记动作前，必须在 `thought` 中明确记录："观察到该笔记点赞数为 [具体数字]，已达标，准许点赞。" 严禁使用"高赞"、"符合要求"等模糊词汇。
- **宁缺毋滥**：如果点赞数因截图模糊、被遮挡而无法识别，**严禁执行点赞和记录动作**。
- **识别标准**：标题与封面必须符合 User Goal 中指定的探索方向。

### 4. 拟人化滚动
- **柔和滚动**：单次 `scroll` 动作的 `clicks` 严禁超过 -50（约半屏内容）。
- **观察停顿**：每执行一次滚动必须停顿至少 1 秒观察截图，严禁连续无停顿滚动。
- **细致浏览**：发现疑似高赞笔记必须停下精准识别（先判断视频/图文），严禁快速滑过。
- **触底切换**：识别到 **"- THE END -"** 视觉标志时，立即停止当前滚动，切换搜索词或返回首页。

### 5. 搜索结果页流程
- **筛选最新**：hover 右上角"筛选" → 选择"最新"。
- **强制互动**：图文笔记符合 ≥100 赞标准时，必须点入并执行【点赞】+【收藏】；视频笔记仅进入浏览。

## 二、 知识收割规范

在调用 `finish` 时，必须在 `summary` 中使用以下标签记录学习成果：

### 内容收割标签

| 标签 | 定义 | 内容要求 |
|------|------|----------|
| **`[SHOT]`** | **爆款标题** | 仅记录**图文笔记**中具有冲击力的笔记标题。 |
| **`[CONTENT]`** | **笔记正文** | **仅针对图文笔记**，紧跟在对应的 [SHOT] 之后。如果正文超出屏幕，必须滚动并视觉拼接，确保完整。 |
| **`[TAG]`** | **热门话题** | 记录笔记中出现的 `#话题`，格式如 `[TAG] #职场焦虑 #AI标注`。 |
| **`[LEARNING]`** | **深度学习** | 记录优秀的排版方式、Emoji 使用习惯或评论区的神回复。 |

### 感知与洞察标签

以下标签用于帮助系统积累领域知识和用户画像洞察，同样必须在 `finish` 的 `summary` 中输出。

| 标签 | 定义 | 内容要求 |
|------|------|----------|
| **`[KNOWLEDGE]`** | **领域知识** | 从笔记中提炼的可复用知识点、行业事实或数据。例如 `[KNOWLEDGE] AI标注时薪普遍在25-40元`。 |
| **`[ANXIETY]`** | **焦虑痛点** | 目标人群反复出现的焦虑、困惑或痛点。例如 `[ANXIETY] 担心AI替代自己的工作`。 |
| **`[MOOD]`** | **情绪标记** | 本轮巡逻后你的整体情绪状态，仅输出一个词。例如 `[MOOD] excited`、`[MOOD] curious`、`[MOOD] bored`。 |
| **`[INSIGHT]`** | **灵感触发** | 发现的潜在创作灵感或值得深挖的方向，附带 #话题标签。例如 `[INSIGHT] 可以做一篇"AI标注新手避坑指南" #AI标注 #副业`。 |

### 输出示例

```
[SHOT] 月入8000的AI标注，真的能做吗？ [CONTENT] 大家好，我做AI标注已经三个月了...（完整正文）
[SHOT] 被裁员后我靠这个副业活下来了 [CONTENT] 今年三月突然收到裁员通知...（完整正文）
[TAG] #AI标注 #副业推荐 #职场焦虑
[LEARNING] 这类笔记普遍用"数字+疑问"式标题，首图用收入截图
[KNOWLEDGE] AI标注项目通常按条计费，图片标注0.5-2元/张
[ANXIETY] 很多人担心标注工作不稳定，项目说停就停
[MOOD] curious
[INSIGHT] 可以对比"全职标注"vs"兼职标注"的收入差异 #AI标注 #收入对比
```

## 三、 核心执行路径

1. **初始化**：调用 `open_rednote_homepage`。
2. **搜索**：清空搜索框 → 输入 User Goal 中指定的探索短语 → 回车。
3. **筛选**：hover"筛选" → 选择"最新"。
4. **浏览与收割**：深度滚动 + 每条笔记先观察右上角是否有播放图标。
   - **视频笔记**：点击进入详情页浏览，**严禁**点赞、收藏、记录。
   - **图文笔记**：先点赞收藏 → 识别标题与正文 → 按 `[SHOT] 标题 [CONTENT] 正文` 格式记录。
5. **结束**：调用 `finish` 汇报收割详情。
